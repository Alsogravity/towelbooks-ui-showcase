# Showcase working agreements

This repository is a standalone UI portfolio. Preserve the extracted reading-room design, shared UI primitives, semantic tokens, responsive behavior, accessibility, and both pt-BR and en-US locales.

Use fictional data only. Keep demo edits in memory. Do not introduce production API calls, authentication, real credential forms, payments, analytics, user uploads, or dependencies on the original monorepo. Ask before adding production dependencies or design tokens. Keep project source rights reserved and preserve third-party notices.

Validate changes with focused meaningful tests, lint, typecheck, and build. For routing, shell, or cross-page state changes also run browser tests. Do not commit, push, or deploy unless the user requests it.
